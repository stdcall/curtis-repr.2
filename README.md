# Methods of Representation Theory, Volume II

Charles W. Curtis and Irving Reiner. With Applications to Finite Groups and Orders. John Wiley & Sons, 1987.

The book covers algebraic K-theory, class groups, blocks, groups of Lie type, rationality, indecomposable modules and representation rings.

The [releases](https://github.com/stdcall/curtis-repr.2/releases) provide the book with editorial notes, a separate list of corrections and SHA-256 checksums.

References to Volume I link to `curtis-repr.1.pdf`, release `2026-11-03.9`.
Keep both volumes in the same directory and use a PDF viewer that supports
links between documents.
